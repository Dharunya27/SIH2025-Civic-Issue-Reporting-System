# 🏛️ Civic Issue Reporting System - React UI

Modern interactive frontend for the Smart India Hackathon 2025 Civic Issue Reporting & Resolution System.

## ✨ Features
- **Citizen Portal**:
  - Voter ID login & registration
  - Geotagged issue reporting with automatic browser GPS detection
  - Photo attachment & category selection (Roads, Street Lights, Garbage, Water Supply, etc.)
  - Real-time tracking of personal issues with SLA deadline timers and status updates
- **Municipal Administrator Portal**:
  - Government ID login & registration
  - Live Area Analytics (Total, Pending, In Progress, Resolved)
  - Issue filtering by Category, Status, Ward, and SLA Urgency
  - Status updates with resolution audit logs
  - Field worker dispatch and worker registry management

## 🚀 Running Locally
```bash
# 1. Install dependencies
npm install

# 2. Run Vite dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. All API requests are automatically proxied to the Spring Boot backend on port 8080.
